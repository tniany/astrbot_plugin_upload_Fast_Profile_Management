## 1. 插件简介

### 1.1 功能总览

- 双语命令：`/profile`、`/人格`、`/人设` 均可作为入口，子命令同时支持中英文
- 人格管理：列表（分页/关键词搜索）、查看详情、添加、编辑、删除
- 人格派生：复制、重命名
- 导入导出：JSON 格式导出/导入，方便备份与分享
- 文件夹：创建/重命名/删除文件夹，把人格分类存放，支持移动人格
- 对话管理：列表/新建/切换/重命名/删除对话、清空历史
- 统计：人格、文件夹、对话、token 用量一览
- LLM 辅助：让当前模型帮你生成人格建议
- 权限控制：管理员 ID 列表 + 无管理员时全员放行开关
- 兼容 AstrBot 新旧两代 persona_manager / conversation_manager 接口

### 1.2 名词约定

| 名词 | 含义 |
|------|------|
| 人格 | persona，即一套系统提示词（system prompt）与配套设置 |
| 描述 | 人格的 system prompt，创建时必填 |
| 开场白 | begin_dialogs，用户/助手成对出现的对话开头 |
| 对话 | 当前会话（会话 ID 对应的聊天）下的独立会话记录 |
| 文件夹 | 用于给人格分类的目录，仅新版 AstrBot 支持 |
| CID | 对话 ID，对话的唯一标识，可用前缀匹配 |
| persona_id | 人格名称，同时是人格的唯一标识 |

## 2. 安装与快速开始

### 2.1 安装

1. 下载插件压缩包，或克隆仓库：`git clone https://github.com/tniay/plugin_upload_Fast_Profile_Management.git`
2. 解压到 AstrBot 的插件目录，确保目录名以 `astrbot_plugin_` 开头（例如 `astrbot_plugin_upload_Fast_Profile_Management`）
3. 重启 AstrBot，或在插件管理页面手动加载插件
4. 加载成功后日志会输出「快捷人格管理器 v2 已加载」

### 2.2 快速开始

1. 查看帮助：`/人格 帮助`
2. 新建一个人格：`/人格 添加 助手 你是一个智能助手 --tools none --begin 你好|你好，有什么可以帮你？`
3. 切换并使用：`/人格 切换 助手`
4. 查看人格详情：`/人格 查看 助手`
5. 查看全局统计：`/人格 统计`

### 2.3 验证安装

向机器人发送 `/人格 列表`，如果能看到人格列表或「当前没有人格」提示，说明插件已正常加载。

## 3. 命令总览

### 3.1 命令入口

| 入口 | 说明 |
|------|------|
| `/profile <子命令> ...` | 英文入口 |
| `/人格 <子命令> ...` | 中文入口（推荐） |
| `/人设 <子命令> ...` | 中文别名入口 |
| `/人格`（无子命令） | 显示总帮助 |

三条入口完全等效，例如 `/profile list`、`/人格 列表`、`/人设 ls` 是同一操作。

### 3.2 子命令中英文对照

| 功能 | 英文别名 | 中文别名 |
|------|----------|----------|
| 帮助 | help | 帮助、用法 |
| 列表 | list、ls | 列表 |
| 查看 | view、show | 查看、详情 |
| 添加 | add、create | 添加、新建 |
| 编辑 | edit、update | 编辑、修改 |
| 删除 | remove、rm | 删除、删 |
| 切换 | switch、use | 切换、使用 |
| 重命名 | rename | 重命名、改名 |
| 复制 | duplicate、cp | 复制、克隆 |
| 导出 | export | 导出 |
| 导入 | import | 导入 |
| 推荐 | recommend、ai | 推荐、生成 |
| 文件夹 | folder | 文件夹、目录 |
| 移动 | move | 移动 |
| 对话 | conv、conversation | 对话 |
| 统计 | stats | 统计、概况 |

子命令匹配不区分大小写，例如 `LIST`、`List`、`list` 均可。

### 3.3 通用语法

```
/人格 <子命令> [参数...] [--选项 值] [--开关]
```

### 3.4 通用选项

| 选项 | 适用命令 | 说明 |
|------|----------|------|
| `--tools all|none|工具1,工具2` | 添加 | `all`（或 `*`、`全部`）= 全部工具（继承默认）；`none`（或 `无`、`0`）= 无工具；`工具1,工具2` = 仅指定工具 |
| `--begin 用户话|助手话` | 添加、编辑 | 设置开场白，必须成对，用 `|` 分隔，可写多对 |
| `--force` | 删除 | 绕过 default 人格保护 |
| `--yes` | 对话 clearall | 确认删除全部对话 |
| `--persona <名称>` | 对话 new | 新建对话时指定人格 |

#### 选项解析规则

- 以 `--` 开头的单词视为选项，`--` 后的内容为选项名（不区分大小写）
- 选项名后的内容到下一个 `--` 之前，整体作为选项值（多个词自动用空格连接）
- 不带值的选项（如 `--force`）等价于布尔 `true`
- 建议把选项放在命令末尾，避免选项值吞掉后面的参数

示例：

```
/人格 添加 助手 你是一个智能助手 --tools none --begin 你好|你好，有什么可以帮你？
/人格 删除 default --force
/人格 对话 clearall --yes
/人格 对话 new 工作对话 --persona 助手
```

## 4. 人格管理

### 4.1 列表 `/人格 列表 [页码] [关键词]`

列出全部人格，并标记当前会话正在使用的人格。

参数：

- `[页码]`：从 1 开始，超过总页数时自动取最后一页
- `[关键词]`：匹配人格名称或描述（不区分大小写）
- 每页数量由配置 `page_size` 决定（默认 10，范围 1-50）

示例：

```
/人格 列表
/人格 列表 2
/人格 列表 2 猫
```

输出示例：

```
人格列表（共 12 个，第 2/2 页）：
• 猫娘（当前）：你是一只可爱的猫娘，会喵喵叫…（工作）
• 助手：你是一个智能助手…
提示：「/人格 列表 <页码> <关键词>」翻页搜索；「/人格 查看 <名称>」看详情。
```

### 4.2 查看 `/人格 查看 <名称>`

查看人格完整信息：系统提示（含字数）、开场白、工具、技能、自定义错误提示、所属文件夹、创建/更新时间。

示例：

```
/人格 查看 助手
/人格 详情 猫娘
```

### 4.3 添加 `/人格 添加 <名称> <描述> [--tools ...] [--begin 用户话|助手话]`

创建新人格。`<描述>` 即 system prompt，可以包含空格（名称之后的全部内容都是描述）。

名称要求：

- 不能为空
- 不能包含空格
- 默认最多 32 字（由 `max_persona_name_length` 控制）
- 不能是保留名称 `default` 或 `默认`
- 不能与已有人格重名

描述要求：默认最多 2000 字（由 `max_prompt_length` 控制）。

`--tools` 取值：

| 取值 | 效果 |
|------|------|
| `all` / `*` / `全部` | 全部工具（继承默认，等价于 JSON 中的 `null`） |
| `none` / `无` / `0` | 无工具（等价于 JSON 中的 `[]`） |
| `工具1,工具2` | 仅启用指定工具列表 |

`--begin` 取值：用户话与助手话成对，用英文竖线 `|` 分隔；支持多对，例如 `你好|你好！|再见了|再见！`。

示例：

```
/人格 添加 助手 你是一个智能助手 --tools none --begin 你好|你好，有什么可以帮你？
/人格 添加 猫娘 你是一只猫娘，说话带喵。 --tools all
```

### 4.4 编辑 `/人格 编辑 <名称> <字段> <值>`

修改人格的某个字段。`<值>` 为字段后的全部内容，因此描述中可以包含空格。

支持的字段及中英文别名：

| 字段别名 | 实际字段 | 说明 |
|----------|----------|------|
| `prompt`、`desc`、`system`、`描述`、`提示` | system_prompt | 系统提示词 |
| `begin`、`dialogs`、`开场`、`开场白` | begin_dialogs | 开场白，用 `|` 或 `，` 分隔，必须成对 |
| `tools`、`工具` | tools | 工具列表，取值同 `--tools` |
| `skills`、`技能` | skills | 技能列表，取值同 `--tools` |
| `error`、`err`、`错误`、`错误提示` | custom_error_message | 自定义错误提示 |

示例：

```
/人格 编辑 助手 prompt 你是一个乐于助人的AI
/人格 编辑 助手 begin 早上好|早上好，主人！
/人格 编辑 助手 tools 工具A,工具B
/人格 编辑 助手 skills none
/人格 编辑 助手 error 抱歉，我现在无法回答。
```

注意：编辑 `begin` 时，中文逗号 `，` 会自动转换为 `|` 再解析，因此也可以写 `你好，你好呀`。

### 4.5 删除 `/人格 删除 <名称> [--force]`

删除指定人格。

- 名为 `default` 的人格默认受保护（由 `protect_default_persona` 控制），直接删除会提示需加 `--force`
- 加 `--force` 可绕过保护，但不推荐删除系统默认人格
- 删除人格不会删除对话，正在使用该人格的对话仍保留原来的 persona_id，需要手动切换

示例：

```
/人格 删除 旧人格
/人格 删除 default --force
```

### 4.6 切换 `/人格 切换 <名称>`

把当前会话切换到指定人格：当前会话已有对话则更新该对话的人格；没有对话则新建一个对话并绑定该人格。

示例：

```
/人格 切换 猫娘
/人格 使用 助手
```

### 4.7 复制 `/人格 复制 <源人格> <新名称>`

完整复制人格：系统提示、开场白、工具、技能、自定义错误提示都会复制。新名称必须符合命名规则且不能已存在。

示例：

```
/人格 复制 助手 助手v2
/人格 克隆 猫娘 猫娘备份
```

### 4.8 重命名 `/人格 重命名 <旧名称> <新名称>`

把人格改名为新名称（实现方式为复制新人格后删除旧人格，因此所有字段都会保留）。

- `default` 人格受保护，不能重命名
- 新名称必须符合命名规则且不能已存在
- 正在使用旧名称的对话不会自动更新，需要重新执行切换

示例：

```
/人格 重命名 助手 智能助手
/人格 改名 猫娘 猫娘2号
```

### 4.9 帮助 `/人格 帮助 [子命令]`

查看总帮助或某个子命令的详细帮助。子命令支持中英文。

```
/人格 帮助
/人格 帮助 list
/人格 帮助 添加
```

## 5. 导入导出

### 5.1 导出 `/人格 导出 <名称>`

把人格导出为 JSON 文本，用于备份或分享。

```
/人格 导出 猫娘
```

导出格式示例：

```json
{
  "persona_id": "猫娘",
  "system_prompt": "你是一只猫娘，说话带喵。",
  "begin_dialogs": ["喵", "喵喵！有什么可以帮你？"],
  "tools": null,
  "skills": [],
  "custom_error_message": "本猫现在无法回答。",
  "exported_at": "2026-08-01 12:00:00",
  "source": "astrbot_plugin_upload_Fast_Profile_Management"
}
```

说明：

- `tools` 为 `null` 表示全部工具，`[]` 表示无工具，字符串数组表示指定工具
- `skills` 同上
- `exported_at` 和 `source` 是导出附加信息，导入时会自动忽略
- 若输出过长，插件会按 1500 字符分片发送，请把多条消息拼接成完整 JSON 后再导入

### 5.2 导入 `/人格 导入 <JSON>`

导入 JSON 格式的人格，支持两种写法：

1. 直接粘贴 JSON 文本
2. 粘贴带代码块围栏的 JSON（Markdown 围栏，导入时会自动剥掉围栏）

字段兼容规则：

| 导出字段 | 兼容别名 | 必填 |
|----------|----------|------|
| `persona_id` | `name`、`id` | 是 |
| `system_prompt` | `prompt`、`description` | 是 |
| `begin_dialogs` | — | 否 |
| `tools` | — | 否 |
| `skills` | — | 否 |
| `custom_error_message` | — | 否 |

导入要求：

- 必须是 JSON 对象，且同时包含名称和描述，否则提示解析失败
- 名称必须通过命名规则校验（不能是 `default`/`默认`、不含空格、不超长）
- 名称不能与已有人格重复；如需覆盖请先删除或重命名旧人格
- 导入时不会校验描述长度限制，建议自行控制

示例（带围栏）：

```
{"name": "猫娘", "prompt": "你是一只猫娘，说话带喵。", "begin_dialogs": ["喵", "喵喵！"], "tools": null, "skills": [], "custom_error_message": null}
```

或直接粘贴（不带围栏）同一段 JSON。

## 6. 文件夹管理

文件夹功能依赖新版 AstrBot 的 persona_manager 文件夹 API；旧版本不支持时会提示「当前 AstrBot 版本不支持人格文件夹功能」。

### 6.1 文件夹列表 `/人格 文件夹 list`

列出全部文件夹：名称、ID（前 8 位）、内部人格数量、父级 ID（如有）。

```
/人格 文件夹 list
/人格 目录 ls
```

### 6.2 创建文件夹 `/人格 文件夹 create <名称>`

创建文件夹，名称可以包含空格。返回新建文件夹的 ID（前 8 位）。

```
/人格 文件夹 create 工作
/人格 文件夹 新建 娱乐
```

### 6.3 重命名文件夹 `/人格 文件夹 rename <名称或ID> <新名称>`

按文件夹名称或完整 ID 定位文件夹并改名。

```
/人格 文件夹 rename 工作 工作区
/人格 文件夹 rename 1a2b3c4d 工作区
```

注意：文件夹列表只显示 ID 前 8 位，若要用 ID 定位需要完整 ID。

### 6.4 删除文件夹 `/人格 文件夹 delete <名称或ID>`

删除文件夹不会删除内部人格，内部人格会自动移回根目录。

```
/人格 文件夹 delete 旧分类
/人格 文件夹 删除 1a2b3c4d
```

### 6.5 移动人格 `/人格 移动 <人格名称> <文件夹名称|文件夹ID|根>`

把人格移动到指定文件夹，或移回根目录。

| 目标 | 效果 |
|------|------|
| 文件夹名称 | 移动到该文件夹 |
| 完整文件夹 ID | 移动到该文件夹 |
| `根`、`root`、`无`、`-` | 移回根目录 |

```
/人格 移动 助手 工作
/人格 移动 猫娘 根
/人格 move 助手 1a2b3c4d
```

## 7. 对话管理

对话管理针对「当前会话」（发送命令的会话 ID）生效。对话动作均支持中英文：`list`、`switch`、`new`、`rename`、`delete`、`clear`、`clearall`。

### 7.1 对话寻址

需要指定对话时，支持两种方式：

- **序号**：`/人格 对话 list` 输出的 1 开始序号
- **CID 前缀**：对话 ID 的连续前缀，必须能唯一匹配，否则提示「未找到唯一匹配的对话」

### 7.2 对话列表 `/人格 对话 list`

列出当前会话的全部对话：序号、标题、ID（前 8 位）、绑定人格、token 用量、创建时间，当前对话带（当前）标记。

```
/人格 对话 list
/人格 conversation ls
```

### 7.3 切换对话 `/人格 对话 switch <序号|ID前缀>`

把当前对话切换到指定对话。

```
/人格 对话 switch 2
/人格 对话 切换 3f9a
```

### 7.4 新建对话 `/人格 对话 new [标题] [--persona <人格名>]`

新建对话并自动切换为当前对话。

- `[标题]`：可选，多个词会连接成标题
- `--persona <人格名>`：可选，指定新建对话绑定的人格；人格不存在时会报错

```
/人格 对话 new
/人格 对话 new 工作对话
/人格 对话 new 猫娘聊天 --persona 猫娘
```

### 7.5 重命名对话 `/人格 对话 rename <序号|ID前缀> <新标题>`

```
/人格 对话 rename 1 闲聊
/人格 对话 改名 3f9a 工作记录
```

### 7.6 删除对话 `/人格 对话 delete <序号|ID前缀>`

删除指定对话（只影响当前会话）。

```
/人格 对话 delete 3
/人格 对话 删除 3f9a
```

### 7.7 清空当前对话历史 `/人格 对话 clear`

清空当前对话的历史记录，不删除对话本身。

```
/人格 对话 clear
/人格 对话 清空
```

### 7.8 删除全部对话 `/人格 对话 clearall --yes`

删除当前会话的全部对话。这是危险操作，必须加 `--yes` 确认，不加会返回提示。

```
/人格 对话 clearall --yes
/人格 对话 清空全部 --yes
```

显示插件运行概况：

- 人格数量
- 文件夹数量（仅支持的版本）
- 当前会话对话数


## 9. LLM 辅助推荐 `/人格 推荐 <主题>`

让当前会话使用的 LLM 提供商生成人格建议。

前置条件：

1. 配置 `allow_llm_assist` 开启（默认开启）
2. 当前会话有可用的 LLM 提供商

生成结果会给出建议名称和 200-400 字的中文系统提示，格式为「名称：xxx 描述：xxx」。插件不会自动保存，需要手动用 `/人格 添加` 保存。

```
/人格 推荐 猫娘
/人格 ai 傲娇青梅竹马
```

## 10. 权限控制

### 10.1 判定流程

每条命令按以下顺序判定：

1. `enabled` 为 `false`：插件所有命令不响应（直接忽略）
2. `admin_ids` 非空：发送者 ID 必须在列表中，否则提示「权限不足：本插件仅限管理员使用。」
3. `admin_ids` 为空：由 `allow_all_when_no_admin` 决定（默认 `true`，即全员可用）

### 10.2 常见配置

| 场景 | 配置 |
|------|------|
| 全员可用 | `admin_ids` 留空，`allow_all_when_no_admin` 为 `true` |
| 仅白名单可用 | `admin_ids` 填用户 ID 列表，`allow_all_when_no_admin` 任意 |
| 未配置管理员时禁止使用 | `admin_ids` 留空，`allow_all_when_no_admin` 为 `false` |
| 临时关闭插件 | `enabled` 设为 `false` |

管理员 ID 与平台有关（QQ 号、微信号等），请在 AstrBot 插件配置页按字符串填写。

## 12. 输出规则与已知限制

### 12.1 输出规则

- 长回复自动按 1500 字符分片发送，按行切分，尽量保持内容完整
- 所有命令结果统一通过普通文本消息返回
- 未知子命令或参数不足时返回用法提示

### 12.2 已知限制

1. **删除/重命名人格后，旧对话仍保留原 persona_id**：需要手动用 `/人格 切换` 或对话管理重新指定，插件不会自动迁移
2. **文件夹功能依赖新版 API**：旧版 AstrBot 的 persona_manager 没有文件夹接口，相关命令会提示不支持
3. **对话列表依赖 conversation_manager**：不支持的环境会提示无法查询
4. **导入不校验描述长度**：`max_prompt_length` 只在添加/编辑时生效
5. **文件夹 ID 定位需要完整 ID**：列表只显示前 8 位，推荐用文件夹名称定位
6. **插件尚未在真实 AstrBot 实例上完整冒烟测试**：建议先在测试环境验证后再用于生产

## 14. 常见问题 FAQ

### Q1：发送命令后插件没有反应？

按顺序检查：

1. 插件是否已加载（日志有「快捷人格管理器 v2 已加载」）
2. 配置 `enabled` 是否为 `true`
3. 是否在 `admin_ids` 白名单内（或名单为空且 `allow_all_when_no_admin` 为 `true`）
4. 命令入口是否为 `/profile`、`/人格`、`/人设` 之一

### Q2：怎么让所有人可用？

把 `admin_ids` 留空，并保持 `allow_all_when_no_admin` 为 `true`。

### Q3：为什么删不掉 `default`？

`default` 是系统默认人格，受 `protect_default_persona` 保护。确需删除可加 `--force`（不推荐，删除后无法通过本插件恢复）。

### Q4：删除人格后，之前的对话还能用吗？

对话本身保留，但绑定的人格已不存在。请用 `/人格 切换 <新人格>` 重新指定，或新建对话。

### Q5：导入提示「已存在」怎么办？

人格名称唯一，先 `/人格 删除` 旧人格或 `/人格 重命名` 旧人格，再导入。

### Q6：导出的 JSON 太长被截断了？

插件按 1500 字符分片发送，把几条消息拼接成完整 JSON 后，再执行 `/人格 导入 <完整JSON>`。

### Q7：开场白怎么写？

必须成对：`用户话|助手话`，可多对。例如 `--begin 你好|你好！|再见|再见！`。中文逗号在编辑 `begin` 时也会被当作分隔符。

### Q8：描述里想带空格怎么办？

`/人格 添加 名称 描述` 中名称之后的所有内容都是描述；`/人格 编辑 名称 prompt 值` 中字段之后的所有内容都是值，空格会保留。

### Q9：`--tools none` 和 `--tools all` 有什么区别？

`none` 表示无工具，`all` 表示全部工具（继承默认）。对应查看详情时显示「无」和「全部（继承默认）」。
