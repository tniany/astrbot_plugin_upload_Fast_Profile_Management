# 快捷人格管理器 (Fast Profile Management)

![GitHub license](https://img.shields.io/github/license/tniay/plugin_upload_Fast_Profile_Management)
![GitHub release](https://img.shields.io/github/v/release/tniay/plugin_upload_Fast_Profile_Management)

一个功能全面的 AstrBot 人格管理插件：支持双语命令（/profile 与 /人格）、人格增删改查、复制重命名、导入导出、文件夹管理、会话对话管理、统计与 LLM 辅助生成，并内置基于插件配置的权限控制。

📖 详细使用文档见 [docs/使用文档.md](docs/使用文档.md)

## 功能特性

- 双语命令：/profile 与 /人格 均可使用，子命令同时支持中英文
- 人格管理：列表（分页/搜索）、查看详情、添加、编辑、删除
- 人格派生：复制、重命名
- 导入导出：JSON 格式导出/导入，方便备份与分享
- 文件夹：创建/重命名/删除文件夹，把人格分类存放
- 对话管理：新建/切换/重命名/删除对话，清空历史
- 统计：人格、文件夹、对话、token 用量一览
- LLM 辅助：让当前模型帮你生成人格建议
- 权限控制：管理员 ID 列表 + 白名单/全员模式
- 兼容 AstrBot 新旧版本 persona_manager 接口

## 安装方法

1. 下载插件压缩包
2. 解压到 AstrBot 的插件目录
3. 重启 AstrBot 或使用插件管理命令加载插件

## 使用指令

以下所有命令都可用 /profile 或 /人格 开头，例如「/profile list」「/人格 列表」等效。

### 人格管理

| 功能 | 命令 |
|------|------|
| 查看列表 | /人格 列表 [页码] [关键词] |
| 查看详情 | /人格 查看 <名称> |
| 添加人格 | /人格 添加 <名称> <描述> [--tools all\|none\|工具1,工具2] [--begin 用户话\|助手话] |
| 编辑人格 | /人格 编辑 <名称> <字段> <值> |
| 删除人格 | /人格 删除 <名称> [--force] |
| 切换人格 | /人格 切换 <名称> |
| 复制人格 | /人格 复制 <源人格> <新名称> |
| 重命名 | /人格 重命名 <旧名称> <新名称> |
| 导出 | /人格 导出 <名称> |
| 导入 | /人格 导入 <JSON> |
| AI 推荐 | /人格 推荐 <主题> |

编辑支持的字段：prompt（描述）、begin（开场白，用户\|助手成对）、tools（工具）、skills（技能）、error（自定义错误提示）。

### 文件夹管理

| 功能 | 命令 |
|------|------|
| 文件夹列表 | /人格 文件夹 list |
| 创建文件夹 | /人格 文件夹 create <名称> |
| 重命名文件夹 | /人格 文件夹 rename <名称或ID> <新名称> |
| 删除文件夹 | /人格 文件夹 delete <名称或ID> |
| 移动人格 | /人格 移动 <人格名称> <文件夹名称\|ID\|根> |

删除文件夹不会删除内部人格，人格会自动移回根目录。

### 对话管理

| 功能 | 命令 |
|------|------|
| 对话列表 | /人格 对话 list |
| 切换对话 | /人格 对话 switch <序号\|ID前缀> |
| 新建对话 | /人格 对话 new [标题] [--persona 人格] |
| 重命名对话 | /人格 对话 rename <序号\|ID前缀> <新标题> |
| 删除对话 | /人格 对话 delete <序号\|ID前缀> |
| 清空历史 | /人格 对话 clear |
| 清空全部对话 | /人格 对话 clearall --yes |

### 其他

- /人格 统计：人格、文件夹、对话、token 统计
- /人格 帮助 [子命令]：查看帮助

## 配置说明

在 AstrBot 插件管理页面的「配置」中可设置：

- 启用插件：总开关
- 管理员ID列表：允许使用本插件的用户 ID
- 无管理员时全员可用：管理员列表为空时是否放行所有用户
- 保护默认人格：禁止删除/重命名 default
- 列表每页数量、人格名称最大长度、人格描述最大长度
- 允许 LLM 辅助：是否启用 /人格 推荐

## 权限说明

- 管理员 ID 在插件配置页设置
- 管理员列表为空时，默认全员可用（可在配置中关闭）
- 非管理员使用指令会收到权限不足提示
